<p align="center">Linux on standalone VR headsets · Linux на автономных VR-шлемах</p>

<p align="center"><a href="https://discord.gg/YwJnEVAcYJ">Discord</a>: chat with us · общайтесь с нами</p>

**KernelXR** brings Linux to standalone VR headsets in place of Android. With our patches any Linux distribution can run on the headset, and we are preparing the patches for submission to the mainline Linux kernel. The first device is PICO 4. The first public builds will be Debian and Arch-based SteamOS. The project is open source and in active development.

**KernelXR** переносит Linux на автономные VR-шлемы вместо Android. С нашими патчами на шлеме может работать любой дистрибутив Linux, а сами патчи мы готовим к отправке в основное ядро Linux. Первое устройство — PICO 4. Первыми публичными сборками будут Debian и SteamOS на базе Arch. Проект открытый и находится в активной разработке.
