<p align="center">Linux on standalone VR headsets · Linux на автономных VR-шлемах</p>

**KernelXR** runs mainline Linux and Debian instead of Android on standalone VR headsets. The first device is PICO 4. The project is open source and in active development.

**KernelXR** запускает основную ветку Linux и Debian вместо Android на автономных VR-шлемах. Первое устройство — PICO 4. Проект открытый и находится в активной разработке.
